# Spec files

The OCPP specifications belong to the Open Charge Alliance and are **not ours to
redistribute**. This directory is never published, packaged or added to the docs
site. Download the files from <https://openchargealliance.org/my-oca/ocpp/> and
place them here (JSON / OCPP-J only; no SOAP).

## `1.6/`
- OCPP 1.6 edition 2 specification (PDF)
- OCPP-J 1.6 specification
- Both errata sheets
- OCPP 1.6 Security Whitepaper (edition 3) and its schemas
- `schemas/` — the JSON schemas

## `2.0.1/`
- OCPP 2.0.1 edition 4: parts 0–2, part 2 appendices, part 4 (OCPP-J), errata
- `appendices-csv/`
- `schemas/`
- Parts 5–6 (certification profiles, test cases), for checking behaviour only

## `2.1/`
- OCPP 2.1 edition 2, same structure as 2.0.1
